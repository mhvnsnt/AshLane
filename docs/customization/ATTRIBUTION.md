## Considered but NOT pulled (license calls)

### MB-Lab — DO NOT use for generated game assets
- License: code GPL-3.0, **data/models AGPL-3.0**.
- MB-Lab's own license doc (`mb-lab-docs/docs/license.rst`) states explicitly:
  models generated by the software are derived products of the AGPL'd database
  and **must be distributed under AGPL 3**. That would force AGPL on any game
  shipping those meshes — unacceptable for this project.
- Exception: 2D renders of MB-Lab scenes are NOT derived products (original
  works) — safe for reference/concept use only.
- Verdict: **reference only** (study the parametric approach, use renders as
  reference). No MB-Lab code, data, or generated meshes in or near the repo.

### MakeHuman — SAFE for generated assets (CC0 exception)
- License: source code + database **AGPL**; but models **exported from an
  official MakeHuman version are released under a CC0 exception** — usable in
  free and non-free/commercial projects, no attribution required
  (per project statements, corroborated by Wikipedia and downstream projects
  like HumanGenerator that rely on the same reading).
- Verdict: generated meshes are CC0 and safe to use; the MakeHuman codebase
  itself stays AGPL — **never vendor it**. Practical note: MakeHuman's last
  stable is 1.2.0 (2020); community fork `makehumancommunity/makehuman` is the
  maintained line. Exported assets (hair, clothes, skin textures) from official
  builds carry the same CC0 exception; community-contributed asset packs on the
  MakeHuman site may carry their own licenses — check per pack.

## Open-source customizer UIs (PATTERNS ONLY — no code copied)

- **M3-org/CharacterStudio** (https://github.com/M3-org/CharacterStudio) — **MIT**.
  Web-based VRM avatar creation on three.js. Patterns worth borrowing:
  `CharacterManager` class centralizing part-swapping state; point-and-click part
  picker + color picker; hot-swap parts on a shared rig; merge-skinned-meshes +
  texture-atlassing optimization pass; export-to-GLB. MIT would permit reuse
  with attribution, but this lane takes patterns only.
- **dragoon788/character-creator** (https://github.com/dragoon788/character-creator) —
  single-page avatar customizer: six category panels (Head/Hair/Body/Eyes/Nose/Mouth),
  hot-swappable meshes re-bound to one shared armature, live material tint,
  bone-level face positioning with per-head offset tables, windowed category
  carousel. Directly mappable to our 7-item suite's UI.
- **richardanaya/aframe-avatar** — **MIT**. Bone-slider editor pattern for
  fine-tuning (relevant to face sliders if the suite ever adds them).

## Gaps (no clean open-source pull found)

- **Masks, gloves, shoes as separate parts:** no CC0 pack with cleanly separated
  accessory parts was found. KayKit/Kenney characters are single-piece;
  Quaternius free tier has no outfits (that's the paid Source tier).
  Recommendation: model these from the attire-pull references, or extract via
  the Quaternius paid Source tier if the owner buys it (outfits + 20 hairstyles
  are Source-tier).
- **Long hair beyond the two staged options:** staged = Quaternius `Hair_Long`
  + OGA dread ponytail. Paid/royalty-free-but-unclear options (CGTrader, Sketchfab)
  were deliberately skipped per the license rule.
- **Face paint textures:** none pulled — paint is better done with the bake-to-
  texture technique (see `customization-pulls/notes/decal-techniques.md`) on the
  game's own face UVs than with stock decals.
