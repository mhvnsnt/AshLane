# AshLane Development Rules (Owner Law)

## 1. SEE, Don't Guess
Run the actual game. Capture real footage/screenshots. Tie every claim to pixels.
Previous agents worked blind — never again.

## 2. Research Real Games, Don't Bullshit
When inspired by a game (Yakuza, Witcher, GTA, Urban Reign, Def Jam, Tekken, Batman, Mad Max):
- Actually research how that game works. Read walkthroughs. Watch gameplay.
- Name specific mechanics, not vague "it's immersive."
- Adapt the mechanic, don't copy assets/story/UI.
- Document the source in the repo.

**NO AI SLOP.** Don't build what you *think* a game should be. Build what the reference games *actually do*, then make it better.

## 3. Pull Open Source, Don't Hand-Tool
- Find CC0/MIT/Apache resources. Verify licenses at pull time.
- Don't reinvent what exists. Federate it in.
- Document what was pulled, where it lives, its license.

## 4. One Character at a Time
Character work runs strictly in priority order. No batching.

## 5. Foundation Before Feel
Rigs, skeletons, animations first. No cosmetic impact effects until characters animate correctly.

## 6. Document Everything in the Repo
Every system, every pull, every decision goes in docs/. If it's not in the repo, it didn't happen.

## 7. No Fake Gameplay
Never advertise with fake footage. Only real gameplay.

## 8. Legal Gate
Only verified open-source/permissive assets. No rips in commercial releases.
WWE/AEW rips get reskinned; owner's generated models keep their likeness.
